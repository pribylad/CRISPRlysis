# project_output_dir (str): Unix path to the folder where the tables and report.txt are written; the charts go to a subfolder named after the subtable and the date, the per-amplicon tables to the subfolder 00_per_amplicon
# add_columns (dic): has nested dictionary, where each key will create new column to the created mastertable and filled with the value
# data_source_original (str): source of the analysed data 
# cut_maximum (int): relative position of the most 5' cleavage site (nucleotides from the optimum cut). Example -2 for SpCas9.
# cut_minimum (int): relative position of the most 3' cleavage site. Example 0 for SpCas9.
# nuclease (str): 'SpCas9' or 'LbCas12a'
# minimum_Reads (int): set the limit for minimum occurance of #Reads for individual mutation output for mastertable_01 (usually set to 5)
# output_format (str): 'png', 'svg', 'any_supported_matplotlib_format'
# make_mastertable_00 (boolean) : True will make new mastertable, False will use the following 'path_to_existing_mastertable_00' key as a path to the existing mastertable
## Subtables for individual 'Alleles_frequency_table_around*.txt' will be created and merged into one 00_mastertable_YYMMDD
# filter_out_values (dic): {'column_name_1':['value_to_be_filtered_out_1', 'value_to_be_filtered_out_2'], 'column_name_2':['value_to_be_filtered_out']} if empty {} no filtration will be done. Example: {'sample':['sgRNA_1_SpCas9_P35S_5_WT_1_0_1', 'sgRNA_1_SpCas9_P35S_5_WT_1_0_2']}
# make_mastertable_01 (boolean) : True will make new mastertable, False will use the following 'path_to_existing_mastertable_01' key as a path to the existing mastertable
## Additional columns will be added to the 00_mastertable_YYMMDD based on the names where individual 'Alleles_frequency_table_around*.txt' were. The names must follow the strict rules for naming the samples for CRISPResso2 analysis -> Order_Nuclease_targetedGene_TargetNum_Mutant_NoOfTargets_Overhangs_Replicate
# make_subtables (boolean): True will make subtables from mastertable_01 according to list in 'subtables_param'. Parameters are names of mastertable columns and subtables are made as unique values from the column. Like to make individual analysis for each unique gRNA/mutant/...
# path_to_existing_subtable_02: set make_subtables as False and use this path for analysing specific pathway, keep '' if you do not want to make subtables and process mastertable_01 directly
# subtables_param (list): [list, of, parameters]
## Use True/False columns as boolean (not as string) -> example: 'Unedited':[True]
## Use numbers as integers when column contains only numbers (not as string) -> example: 'n_deleted':[0]
## Use numbers as strings when column contains numbers and also strings -> example: 'Gap_around_cut_starts':['90']
# show_plots (boolean): define if the plots will be shown during the code is running
# plot_INDELs (boolean): controls if related charts will be made
# plot_INs (boolean): controls if related charts will be made
# plot_DELs (boolean): controls if related charts will be made
# plot_DEL_dinochart (boolean): controls if related charts will be made
# plot_participating_end (boolean): controls if related charts will be made
# plot_DEL_individual_gRNAs (boolean, required): controls if related charts will be made
# plot_participating_end_dinochart (boolean, required): controls if related charts will be made
# (plot_MH and plot_MH_dinochart are not read by the code any more and were removed from the dictionary)
# IN_greater_than (int): for IN analysis, what is the border for sum up n_inserted, max is 7
# sort_alphabetically (boolean): True will sort samples in mastertable_01 by name before plotting
# list_of_columns (list, optional): column names for folder names that do not follow Order_Nuclease_Gene_gRNAnum_Mutant_NoOfTargets_Overhangs_Replicate. MUST be kept when such a dataset is re-run.
# cut_position (int, optional): value set as 'offset_around_cut_to_plot' in the CRISPResso2 analysis; fallback only, the cut is detected per sample from gRNA + PAM

# skip_multi_gap_run_alleles (True), collapse_identical_alleles (False),
# plot_INDEL_horizontal_barcharts / plot_IN_horizontal_barcharts / plot_DEL_horizontal_barcharts / plot_participating_end_horizontal_barcharts (True),
